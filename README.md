# Student-Academic-Performance-Analytics-System
A Java-based system for managing and analyzing student academic performance using OOP, exception handling, multithreading, file I/O and basic analytics.

A Java-based academic performance analytics system developed as a Capstone Project for Object Oriented Techniques using Java.

## Features

- Student record management
- Subject-wise performance analysis
- Average marks calculation
- Highest and lowest marks
- Pass/Fail analysis
- Student searching
- Marks-based sorting
- Input validation
- Custom exception handling
- File handling
- Multithreading
- Report generation

## Technologies

- Java
- Object-Oriented Programming
- Collections
- Exception Handling
- Multithreading
- File I/O
- TCP Socket Programming

## Project Structure

- `model` – Core data classes
- `service` – Business logic
- `exception` – Custom exceptions
- `util` – Utility functions
- `io` – File/input-output handling
